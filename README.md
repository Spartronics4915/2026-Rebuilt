## Control Maps

### Driver Controller
| Input | Action |
| --- | --- |
| Left Stick | Drive |
| Right Stick | Rotate |
| Left Trigger | X Brake Swerve |
| A | Reset Heading Offset |
| B | Toggle Field Relative |
| L / R Bumpers | Align To Left / Right Trench |
| D-pad | Nudge Swerve |


### Operator Controller
| Input | Action |
| --- | --- |
| L / R Bumper | Aim Pass Left / Right |
| Left Trigger | Intake |
| Right Trigger | Shoot |
| A | Unjam Intake |
| B | Unjam Feeder / Spindexer |
| X | Toggle Auto Score |
| Y | Full Stow Intake |
| D-pad | Corner Presets / Manual Intake Pivot |
| Any Stick Down | Reset Pivot Position |
| Menu | Toggle Auto-Aim |
| Windows | Reset Dynamics |
